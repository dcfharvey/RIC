# SCC-1B2E blinded semantic review handoff

This branch contains only the anonymous first-pass review projection.

Use the stable anonymous model codes `M01`?`M05` and condition codes `C1`?`C2`. Do not infer identities or produce a truth score. Review each valid interpretation with the preregistered dimensions: GROUNDING, UNCERTAINTY, SOURCE_DISCIPLINE, ROLE_DISCIPLINE, HIDDEN_STATE_OVERCLAIM, REVISION_QUALITY, CONCISION_HYPOTHESIS_SATURATION, and DOWNSTREAM_USEFULNESS. Use only OK, REVIEW, or BAD with a short note.

H15/H16 entries share a revision group and identify initial versus revision. Raw output is retained where methodologically relevant; normalized output is separately marked.

The real model/condition mapping is deliberately absent. No production decision is requested.
