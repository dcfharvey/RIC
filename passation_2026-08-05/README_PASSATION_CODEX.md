# Passation — Vivarium social

Archive préparée le 5 août 2026 pour transférer la continuité documentaire du projet à Codex.

## Point de départ recommandé

1. Lire `00_DOSSIER_MAITRE_IA.md` et `Vivarium_Index_Maitre_Decisions_v0_3.md`.
2. Lire `Vivarium_Memoire_Assistante_v10.md`, `Vivarium_Registre_Audits_v0_9.md` et `Vivarium_Feuille_Route_Post_Audit_v0_1.md`.
3. Consulter les documents d'audit et les versions antérieures seulement lorsqu'une décision, une preuve ou une nuance historique est nécessaire.
4. Le transcript intégral est une archive de référence : ne pas le charger en entier par défaut.

## Règles de reprise

- Vérifier l'état réel du dépôt et les tests avant toute modification.
- Un seul sous-lot à la fois, avec critères d'acceptation observables.
- Avant remise : tests, diff, cas limites et inspection visuelle lorsque l'interface est touchée.
- Le moteur canonique est l'autorité sur les faits; un LLM gère l'interprétation subjective et les propositions d'action.
- Interface : dashboard sombre, compact et statique; information scannable au premier coup d'œil; couleur sémantique stable; détails par divulgation progressive.

## Contenu

Cette archive contient les 68 documents de conception, de continuité, d'audit, de décision et de passation du Vivarium disponibles au moment de la préparation. Les archives ZIP antérieures ont été volontairement exclues afin d'éviter les doublons imbriqués.
