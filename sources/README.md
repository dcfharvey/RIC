# Sources de conception RIC

Les fichiers de ce répertoire sont des **matériaux source historiques de conception**.

Ils servent à préserver :

- les formulations initiales;
- la provenance d'exigences et d'idées;
- le contexte nécessaire aux audits et à la recherche;
- les hypothèses qui ont précédé certaines décisions de produit.

Ils ne constituent pas, à eux seuls, la spécification autoritative actuelle.

Une proposition présente dans `sources/` peut avoir été :

- retenue;
- modifiée;
- supersédée;
- différée;
- rejetée;
- ou jamais implémentée.

Avant d'en faire une exigence ou une affirmation sur le runtime actuel, vérifier :

1. `docs/01_REGISTRE_DECISIONS.md` pour le statut de la décision;
2. `docs/00_DOSSIER_MAITRE_IA.md` pour les invariants normatifs stables;
3. `docs/03_DECISIONS_OUVERTES.md` pour les arbitrages non fermés;
4. le `PRODUCT_HEAD` réel de `product/current` pour l'état technique.

Ne pas réécrire ces sources pour les conformer rétroactivement au produit : leur rôle est de conserver la provenance.

Voir `docs/INDEX_DOCUMENTAIRE.md` pour la hiérarchie documentaire.
